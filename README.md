1. **Cloner le dépôt** Git et l'ouvrir dans Visual Studio Code.
2. **Ouvrir le Dev Container** : `Ctrl + Shift + P` → `Dev Containers: Rebuild and Reopen in Container`.
3. **Configurer et lancer** : copier `api/.env.example` vers `api/.env`, renseigner les variables d'environnement, puis exécuter `npm run dev` dans le terminal du Dev Container.
